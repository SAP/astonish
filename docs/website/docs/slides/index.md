# Slides

Astonish Slides turns a conversation into a complete presentation. Use Chat to generate and refine the content, edit the result directly in Studio, save it to the Slides library, and present or export it when it is ready.

Slides can work from a short prompt, a detailed brief, attached documents and images, research performed by the agent, or information from connected systems that the agent can access.

<!-- IMAGE: Slides library with personal and team presentations -->

## How Slides Works

1. Start from **Slides → Create Slide**, or ask for a presentation in **Chat**.
2. Tell Astonish about the purpose, audience, source material, desired length, and visual style.
3. Choose a built-in or imported template.
4. Review the deck as it is generated, then request changes in Chat or edit existing objects on the canvas.
5. Select **Save** to add the session draft to the Slides library.
6. Present it in the browser, publish or fork it where available, or export it as PPTX, PDF, or HTML.

## Slides in Studio

**Chat** is the authoring workspace. It shows generation progress and an interactive deck preview, including while the first slides are still being created.

**Slides** is the permanent library. It contains saved personal decks and, in platform mode, decks shared with the current team. Open **Templates** from this view to browse available presentation designs.

Personal decks and templates are available in both personal and platform deployments. Platform deployments can also provide inherited team, organization, and platform templates, plus personal-to-team publishing and team-to-personal forking.

## Current Limits

- Slides use a fixed 16:9 canvas rather than a responsive page layout.
- Direct canvas editing changes existing text and objects. Ask Chat to add new content structures, images, or other substantial changes.
- Imported PowerPoint templates provide brand identity and representative layouts, but they are not a browser-based PowerPoint template editor.
- Export fidelity varies by format. PDF prioritizes visual consistency, while PPTX prioritizes editable PowerPoint objects where supported.
